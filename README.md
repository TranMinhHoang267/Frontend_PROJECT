# 💼 Website Tuyển Dụng & Tìm Kiếm Việc Làm (Job Portal)

Dự án Website Tuyển dụng hiện đại được phát triển bằng **React**, **TypeScript** và **Vite**. Hệ thống được thiết kế tối ưu trải nghiệm người dùng với giao diện đẹp mắt, hỗ trợ đầy đủ tính năng cho Ứng viên, Nhà tuyển dụng và Quản trị viên.
